# PathFinder DQN

**PathFinder DQN** — учебный проект по обучению агента с подкреплением находить путь от старта `S` до цели `G` на текстовых картах с препятствиями `H`.

В проекте реализованы три варианта агента:

- `DQNAgent` — базовый Deep Q-Network;
- `DoubleDQNAgent` — DQN с отдельной target-сетью для более стабильного обучения;
- `DuelingDQNAgent` — Dueling DQN, разделяющий оценку состояния и преимущества действий.

Основной запуск находится в файле `run_training.py`. Карты хранятся в папке `maps/`.
